# NIT_train_front

`NIT_train` 학습 API 의 웹 콘솔. 드론/CCTV 영상을 **구간 선별 → 회전박스(OBB) 라벨링 →
데이터셋 → 학습 → 모델 승격**까지 화면에서 끝낸다.

빌드 도구가 없다. 순수 ES 모듈 + CSS 다.

- 온프레미스(폐쇄망)에서 `npm install` 이 막히는 경우가 많다. 배포가 "폴더 하나 정적 서빙" 으로 끝나야 한다.
- 이 화면에 필요한 것(캔버스 편집, 표, 폴링)은 프레임워크 없이도 충분하다.

---

## 1. 실행

학습 API 를 먼저 띄운다.

```bash
conda activate NIT
python NIT_train/src/api.py          # http://127.0.0.1:8888
```

콘솔을 띄운다.

```bash
python NIT_train_front/server.py                        # http://127.0.0.1:8890
python NIT_train_front/server.py --port 9000
python NIT_train_front/server.py --api http://10.0.0.5:8888
```

`server.py` 는 표준 라이브러리만 쓴다. 파이썬 없이 nginx 로 이 폴더를 서빙해도 동작한다.

### API 주소

우선순위는 다음과 같다.

1. 브라우저에 저장된 값 — 우측 상단 상태 칩을 눌러 바꾼다(`localStorage`)
2. `server.py --api ...` 로 심은 값 (`assets/js/api-base.js`)
3. 기본값 — 콘솔을 서빙한 호스트의 `:8888`

API 는 CORS 를 열어 두므로 프런트와 API 를 다른 호스트/포트에 두어도 된다.

## 2. 화면과 작업 순서

탭 번호가 파이프라인 순서다. 각 화면 오른쪽 위에 다음 단계로 가는 버튼이 있다.

| 탭 | 하는 일 |
| --- | --- |
| **1 · 영상** | 업로드(드래그&드롭) 또는 서버 경로 등록(복사 없음). 카드에 구간·라벨링 진행률이 보인다 |
| **2 · 구간** | 재생하며 정상/비정상 구간 지정 → 프레임 추출 + 자동 라벨 초안 생성 |
| **3 · 라벨링** | 회전박스 검수/수정, 객체(track) 단위 클래스 일괄 지정, 승인 |
| **4 · 데이터셋** | 승인 라벨로 빌드 · 기존 `train_data` 폴더 등록 · 기존+신규 병합 |
| **5 · 학습** | 데이터셋+가중치 선택 → 학습. 진행률·지표·로그 3초 자동 갱신, 중단/이어서 |
| **6 · 모델** | 가중치 목록, 승격 이력, 추론 서비스로 배포 |

### 중요: 첫 자동 라벨은 비어 있을 수 있다

사전학습 가중치(COCO 80 / DOTA 15)는 **탑다운 드론 영상의 10px 표적을 하나도 못 잡는다.**
실제로 확인한 결과, `yolo26l.pt` 와 `yolo26l-obb.pt` 모두 이 영상 도메인에서 conf 0.05 에도
탐지가 0이다. 그래서 순서는 이렇게 된다.

1. **부트스트랩** — 이미 라벨된 데이터셋(`tracker_py/train_data/preprocessed_obb`)을
   `4 · 데이터셋 → 기존 YOLO 폴더 등록` 으로 올리고 바로 학습한다.
2. 학습 결과를 `6 · 모델` 에서 승격한다.
3. 새 영상은 `2 · 구간` 의 **초안 생성 가중치**에서 그 승격 모델을 골라 추출한다.
   이제 초안이 실제로 나오고, 사람은 고치기만 한다.

초안이 없는 첫 영상은 라벨링 화면에서 직접 그린다(빈 곳 드래그 → 박스 생성).

## 3. 라벨링 단축키

| 키 | 동작 |
| --- | --- |
| `1`…`9`, `0` | 선택한 박스에 클래스 지정 (목록 순서 = 학습 클래스 id) |
| `Q` / `E` | 회전 −1° / +1° (`Shift` 5°) |
| `←` `↑` `↓` `→` | 선택 박스 1px 이동 (`Shift` 10px) |
| `Del` / `Backspace` | 선택 박스 삭제 |
| `Tab` | 다음 박스 선택 · `Esc` 선택 해제 |
| `S` | 저장 · `Enter` 승인하고 다음 · `R` 제외 |
| `[` `]` | 이전/다음 프레임 |
| 휠 | 확대/축소 · `Space`+드래그(또는 `Shift`+드래그) 화면 이동 |

마우스: 빈 곳 **드래그** = 새 박스, 박스 내부 드래그 = 이동, 꼭짓점 = 크기,
위쪽 원형 핸들 = 회전.

프레임을 넘기거나 화면을 벗어나면 수정 중이던 라벨은 **자동 저장**된다.

### 회전박스가 항상 직사각형인 이유

편집 중에는 4점을 자유롭게 옮기지 않고 `{중심, 폭, 높이, 각도}` 로 다룬 뒤 저장할 때만
4점 폴리곤으로 되돌린다(`assets/js/obb.js`). 4점을 자유 이동하게 하면 사다리꼴이 만들어지고,
그 라벨은 YOLO OBB 학습에서 에러 없이 이상한 각도로 해석된다.

점 순서는 서버·ultralytics 규약과 같은 시계방향(좌상 → 우상 → 우하 → 좌하)이다.

## 4. 구조

```
NIT_train_front/
├── index.html                 # 단일 페이지 (탭 + 상태칩 + 설정 다이얼로그)
├── server.py                  # 의존성 없는 정적 서버 (--api 로 주소 주입)
├── package.json               # node 로 자체 테스트를 돌리기 위한 최소 설정 (npm install 불필요)
├── assets/
│   ├── css/app.css            # 다크 테마. 프레임 이미지가 주인공이라 UI 는 낮춘다
│   └── js/
│       ├── app.js             # 부트스트랩 · 해시 라우팅 · 공유 상태(작업 중 영상/클래스)
│       ├── api.js             # 모든 엔드포인트 + 잡 폴링 + 업로드 진행률(XHR)
│       ├── api-base.js        # 배포 시 심는 기본 API 주소
│       ├── obb.js             # 회전박스 기하 (폴리곤 ↔ 사각형, 리사이즈/회전)
│       ├── util.js            # DOM·포맷·토스트·이스케이프
│       └── views/             # 탭 하나 = 파일 하나
│           ├── videos.js  segments.js  label.js
│           └── datasets.js  train.js   models.js
├── docs/ui.md                 # 화면 설계와 결정 이유
└── test/
    ├── obb.test.js            # 회전박스 기하 자체 검증 (node)
    └── api_contract.py        # 프런트가 읽는 응답 필드 계약 검증 (백엔드 환경 필요)
```

각 view 모듈은 `render(container, params, app)` 를 내보내고, 정리할 것이 있으면
`{ dispose }` 를 돌려준다. 라우터가 화면을 바꿀 때 `dispose()` 를 반드시 호출하므로
학습 로그 자동 갱신 같은 타이머가 다른 화면에서 계속 도는 일이 없다.

## 5. 테스트

```bash
# 회전박스 기하 (브라우저·서버 불필요)
node NIT_train_front/test/obb.test.js

# 프런트가 기대하는 API 응답 계약 (파이프라인을 실제로 한 바퀴 돌린다)
conda activate NIT
python NIT_train_front/test/api_contract.py
```

`api_contract.py` 는 프런트가 읽는 **필드 이름**이 응답에 있는지 확인한다. 백엔드가 키를
하나 바꾸면 화면은 에러 없이 조용히 `-` 를 그리기 때문에, 그 실패를 눈이 아니라 테스트로 잡는다.
회전박스 좌표가 프런트 → 서버 → 프런트 왕복에서 각도까지 보존되는지도 여기서 본다.

---

## 6. 배포

정적 파일이라 무엇으로 서빙해도 된다.

```dockerfile
FROM nginx:alpine
COPY . /usr/share/nginx/html
```

API 주소를 이미지에 심으려면 빌드 전에 한 번 실행한다.

```bash
python server.py --api http://nit-train:8888 --write-only   # api-base.js 만 갱신하고 종료
```

브라우저에 이전 주소가 저장돼 있으면 그 값이 이깁니다. 상태 칩 → 설정에서 바꾼다.
